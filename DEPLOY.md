# Deploying NVIDIA AI DevOps Assistant

This guide covers how to deploy this engineering platform to **GitHub** and **Render.com**.

## 1. Move to GitHub
1. Create a new repository on GitHub.
2. Push your project code:
   ```bash
   git init
   git add .
   git commit -m "feat: specialized DevOps Engineering Assistant"
   git branch -M main
   git remote add origin https://github.com/manisai901/devops-nim-assistant.git
   git push -u origin main
   ```

## 2. Deploy to Render.com (Recommended)
Render is perfect for this Node.js based full-stack application.

1. **Sign in** to Render and connect your GitHub.
2. Click **New +** > **Web Service**.
3. Select your `devops-nim-assistant` repository.
4. **Configuration Settings**:
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
5. **Environment Variables**:
   In the Render dashboard, go to **Environment** and add:
   - `NVIDIA_API_KEY`: Your key from [NVIDIA Build](https://build.nvidia.com/).
   - `NODE_ENV`: `production`
6. Click **Deploy Web Service**.

## 3. Deployment on High-Performance Clouds
Since this app is container-ready (check the Docker Expert mode for custom Dockerfiles!), you can also deploy it to:
- **AWS App Runner** or **ECS**
- **Google Cloud Run**
- **Azure Container Instances**

Simply use the Dockerfile generated by the **Docker Expert** mode in this app to containerize the build and deploy to any K8s cluster or container service.

---

### Security Note
Always use server-side environment variables for your `NVIDIA_API_KEY`. This application is designed to keep your keys safe on the server and never expose them to the client-side browser.
